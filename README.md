# IQ80

一个帮助你理解复杂概念的 skill，正文只有一句话：

> 用最容易理解的方式解释给我听，假装我的智商只有 80

## 安装到 Codex

将此仓库克隆到 Codex 的 skills 目录：

```sh
git clone https://github.com/d-wwei/IQ80.git "${CODEX_HOME:-$HOME/.codex}/skills/iq80"
```

如果已经安装过 IQ80，无需重复克隆。

## 使用

在对话中输入 `$iq80`，再加上你想理解的内容。例如：

```text
$iq80 给我解释一下什么是注意力机制。
```
